# React Router 首页

React Router 是一个面向 React 的多策略路由器，架起了从 React 18 到 React 19 的桥梁。你可以将其作为一个完整的 React 框架来使用，也可以按需最小化使用。

## 快速开始

React Router 有三种主要的使用方式，即"模式"，因此我们提供了三份入门指南帮助你上手。

- [声明式模式](./start/declarative/installation)
- [数据模式](./start/data/installation)
- [框架模式](./start/framework/installation)

请阅读[选择模式](./start/modes)了解哪种模式适合你。

## 如何使用本文档

在文档中你会看到以下图标：

[MODES: framework, data, declarative]

## 升级指南

如果你已经启用了所有 future flag，从 React Router v6 或 Remix v2 升级通常不会产生破坏性变更。我们建议 Remix v2 应用升级到 React Router v7。

- [从 v6 升级](./upgrading/v6)
- [从 Remix 升级](./upgrading/remix)
