# createSessionStorage

[MODES: framework, data, declarative]

## 概述

[参考文档 ↗](https://api.reactrouter.com/v7/functions/react-router.createSessionStorage.html)

注意：这是一个低级 API，只有在现有的会话存储选项无法满足你的需求时才应使用。
