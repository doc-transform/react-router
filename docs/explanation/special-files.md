# 特殊文件

本页面的内容已移至以下位置：

- [`react-router.config.ts`](../api/framework-conventions/react-router.config.ts) - 应用的可选配置文件
- [`root.tsx`](../api/framework-conventions/root.tsx) - 必需的根路由，渲染 HTML 文档
- [`routes.ts`](../api/framework-conventions/routes.ts) - 必需的路由配置，将 URL 映射到组件
- [`entry.client.tsx`](../api/framework-conventions/entry.client.tsx) - 可选的客户端入口点，用于注水
- [`entry.server.tsx`](../api/framework-conventions/entry.server.tsx) - 可选的服务端入口点，用于渲染
- [`.server` 模块](../api/framework-conventions/server-modules) - 从客户端包中排除的仅服务端模块
- [`.client` 模块](../api/framework-conventions/client-modules) - 从服务端包中排除的仅客户端模块
